# Школа Божої любові · School of God's Love

Двомовна (UA/EN) інтерактивна біблійна школа для дітей 7–12 років.
12 уроків · книга на 12 розділів · 60 запитань · 6 мініігор · диплом.

Весь сайт — один файл index.html: без бібліотек, CDN, реклами й аналітики.
Працює офлайн. Прогрес зберігається в localStorage на пристрої.

Запуск: відкрийте index.html у браузері.
GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).

Історії — авторські адаптації біблійних текстів. Проєкт натхненний
тематикою вчення Віктора Томєва про Божу любов і благодать; це не офіційний
сайт чи продукт пастора.
